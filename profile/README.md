## What Is ColorLogic CoPrA

ColorLogic CoPrA is a profiling helper for a printer you can print a chart on. ColorLogic CoPrA printer profile is the result: a description of that printer on that paper. ColorLogic CoPrA chart measure is how the readings get in. A home photo printer, a study lab, or a small print room can build a profile for the paper they actually load instead of trusting a generic name.

ColorLogic CoPrA devicelink is a different object. It converts from one known condition to another, which is useful when a class file was prepared for one setup and will print on another. ColorLogic CoPrA ink save is a careful version of that link when reducing ink matters and the color shift must stay small. ColorLogic CoPrA gamut view is the picture you look at before you promise a saturated color the paper cannot hold.

Print the chart under the same settings you will use later. Bring the readings into ColorLogic CoPrA chart measure, build ColorLogic CoPrA printer profile, and open ColorLogic CoPrA gamut view before you trust it. Add ColorLogic CoPrA devicelink or ColorLogic CoPrA ink save only after the plain profile already matches a proof you can see.
